<p>预算紧的时候，最容易做的错误决定是「买大不买小」：怕不够用，先买一堆流量和并发，结果每个月月底看后台，用掉的不到三成。住宅 IP 的计费方式这几年在变，按实际占用结算的产品越来越多，但要用得划算，前提是知道自己的占用长什么样。这篇按三类占用形态分开讲，每类给出适配的计费方式和核对方法。</p>
<h2>一、先看自己的占用形态属于哪类</h2>
<p>形态判断不看号量，看时间分布。同样十五个号，每天集中用三小时和全天挂着，账单能差一倍以上。</p>
<h3>三类形态的识别特征</h3>
<p>看后台的时段分布图就行：如果每天有两个明显的波峰、中间基本为零，属于固定时段型；如果一个月里只有几天特别高、其余接近静默，属于项目型；如果全天都有零散请求、峰值始终不超三，属于长尾型。三类对应的最优计费方式完全不同。</p>

<h2>二、场景一：每天固定几小时</h2>
<p>这是最常见也最容易被包月坑的形态。团队每天上午十点到十二点、下午三点到五点各用一轮，其余时间设备闲置，但包月是按线路条数收的，闲不闲都收钱。</p>
<h3>为什么固定时段容易被包月坑</h3>
<p>因为包月把「时间」这个维度抹掉了。一条线包月八十元，每天只用四小时，等于每小时付三元多；如果按占用小时结算，同样的线路可能每小时一元出头。差出来的部分，一年下来够多买几条备用线。</p>
<h3>按占用结算怎么算</h3>
<p>先统计一个月里每小时的并发占用数，累加得到总占用小时。比如每天两轮、每轮五个并发、每轮两小时，一天就是二十个并发小时，一个月约六百。乘以单价，就是账单的基线。再留一成余量应对临时加班，预算就定了。</p>

<h2>三、场景二：项目制短期高峰</h2>
<p>项目型的特点是尖峰很高但很短。这类最忌讳签长约，也最忌讳为了几天的高峰常年维持高并发。</p>
<h3>峰值怎么摊</h3>
<p>先看高峰能持续多久。如果只持续两三个小时，完全可以排队消化，把并发压到峰值的六成；如果持续一整天，就得按峰值买，硬压只会拖慢进度。判断依据是任务的截止时间，不是主观感觉。</p>

<h2>四、场景三：常年低并发养号</h2>
<p>低并发不等于零成本，但确实是三类里最省的一种。关键是别为了一点流量去买高配套餐。</p>
<h3>低并发不等于零成本</h3>
<p>账号需要维持基本的活跃，每天几条请求是常态。这部分流量很小，但线路得一直可用，所以成本主要在「占用一条线」而不是「跑多少数据」。理解这一点，就不会去比流量单价，而会比线路的月费和中途更换的成本。</p>
<h3>包月与按占用的分界</h3>
<p>经验分界是每天四小时。低于四小时，按占用更划算；高于四小时，包月单价更低；刚好在四小时上下，就按季节调：旺季包月，淡季切回按占用。这种切换不需要换服务商，多数后台支持档位调整。</p>
<h2>五、按占用结算怎么核对账单</h2>
<p>按占用的账单比包月复杂，容易对不上。三个核对点能覆盖大部分争议。</p>
<h3>三个核对点</h3>
<p>一是计费粒度，不足一分钟按一分钟还是按一小时，差别很大；二是并发定义，是同一条线的并发，还是全局并发；三是空闲是否计费，有些产品在连接保持但无请求时仍计入占用。三点问清，再拿一个月的数据对一遍，误差应控制在一成以内。</p>

<h2>常见问答</h2>
<h3>按占用结算会不会比包月更贵？</h3>
<p>答：高频使用时确实会。判断标准是每天在线时长，超过四小时包月通常更划算。建议先按占用跑一个月，用真实数据算出来再决定，别凭感觉。</p>
<h3>流量用不完能留到下个月吗？</h3>
<p>答：多数按量产品不结转，少数支持有限结转。这一点签之前必须问清，因为它直接决定你要买多少余量。不结转的话，宁可少买勤补。</p>
<h3>低并发养号需要独享线路吗？</h3>
<p>答：看账号价值。核心号建议独享，因为共享池的地址变动会打断养号节奏；辅助号共享即可，被牵连的成本低。</p>
<h3>旺季切包月、淡季切按占用，会有额外费用吗？</h3>
<p>答：通常没有，但切档可能影响线路分配，导致出口地址变化。切档前先确认能否保留原地址，不能保留的话就把切档安排在业务低谷。</p>
